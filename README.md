# Hangman Game 🎮

A simple command-line Hangman game built with Python as part of my Python learning journey.

## About the Project

In this game, the computer randomly selects a word from a predefined list. The player tries to guess the word by entering one letter at a time.

The player starts with **6 lives**. Each incorrect guess costs one life. The game ends when the player guesses the complete word or runs out of lives.

## Features

- Random word selection using Python's `random` module
- Letter-by-letter guessing
- Displays correctly guessed letters
- Six lives for the player
- Win and lose conditions

## Python Concepts Practiced

- Variables and data types
- Lists
- `random.choice()`
- `for` and `while` loops
- Conditional statements (`if`)
- User input with `input()`
- String methods such as `.lower()`
- List indexing and updating list elements
- Boolean flags to control the game loop

## How to Run

**Requirements:** Python 3 installed on your computer.

1. Clone this repository:

   ```bash
   git clone https://github.com/hariskhan086/python-hangman-game.git
   ```

2. Open the project folder:

   ```bash
   cd python-hangman-game
   ```

3. Run the game:

   ```bash
   python Hangman-Game.py
   ```

## How to Play

1. Run the Python program.
2. Enter a letter when prompted.
3. Guess the hidden word one letter at a time.
4. Avoid incorrect guesses to preserve your lives.
5. Reveal every letter before your lives reach zero to win.
